## Corrections discovered during execution

1. Hosted fetch rejected redirect:error before sending the request. Using redirect:manual and checking response status preserved the no-redirect credential boundary and allowed preflight to pass. The failed attempt and diagnostic remain in evidence.
2. A buffered pre-abort marker was not a reliable acceptance signal. The corrected assertion uses the externally observed abort outcome, changed instance, terminal transcript and independent ledger.
3. The pinned local workerd binary did not support a 22 October compatibility date. The local replay probe now uses the same supported date as the original fixture. No dependency upgrade was substituted for the pinned test.

These are laboratory implementation corrections. The observed Pi replay behaviour matches the tested contract; no upstream Pi defect is claimed.
